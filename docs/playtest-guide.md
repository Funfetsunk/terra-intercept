# Terra Intercept: playtest guide

Thanks for testing! This is a work-in-progress build. Sound effects aren't in yet and the music is placeholder, so it's quieter than the real thing will be.

## Running it

1. Unzip the folder anywhere and run `TerraIntercept_Tester.exe`.
2. Windows may show "Windows protected your PC" because the game isn't code-signed. Click **More info**, then **Run anyway**.
3. A gamepad is recommended (Xbox-style). Keyboard and mouse work too.

## Controls

| Action | Pad | Keyboard / mouse |
|---|---|---|
| Move | Left stick | WASD |
| Fire (aim) | Right stick | Mouse to aim, hold left click |
| Focus (slows enemy bullets) | LT | Shift |
| Pick squad-mate | LB / RB | Q / E |
| Special | RT | Right click |
| Missile | A | Space |
| Pause | Start | Esc |

## Tester extras

- **Every mission is unlocked on the map.** Start a new save, pick a ship, and choose any mission. Missions played ahead of your progress count as replays, so they don't change your save's route.
- **Skip to the boss:** press **F2** or the pad's **Back / View** button during a mission.
- **FPS counter** in the top-right corner.

## The campaign

The map has 13 missions in 8 columns. Each column after London has two lanes; a full playthrough visits one mission per column.

| Column | North lane | South lane |
|---|---|---|
| 1 | London (tutorial) | |
| 2 | Norwegian Fjords | Paris |
| 3 | Siberian Ice | Cairo |
| 4 | Great Wall | Himalayas |
| 5 | Tokyo | Sydney |
| 6 | Grand Canyon | Rio |
| 7 | Orbital | |
| 8 | Homeworld (finale) | |

Difficulty is meant to rise steadily from left to right. The two missions in the same column should feel about equally hard.

## What to report

For each mission you play, please note:

1. **Mission and ship** (for example "Cairo, Guardian").
2. **Difficulty setting** (Options: Easy or Normal).
3. **Lives lost**, and **where**: wave, mid-boss, boss phase, or a twist such as walls, fog, gusts, avalanches, beams or the escape.
4. **How it felt:** too easy / about right / too hard. One sentence on why helps a lot.
5. **Unfair moments:** deaths you couldn't see coming, bullets hidden by the background, or attacks with no warning.
6. **Bosses:** too long, too short, or too spongy? Which phase was hardest?
7. **Performance:** did the FPS counter drop below 60, and where? Include your CPU and graphics card if you can.
8. **Anything broken:** crashes, getting stuck, visual glitches. A screenshot is ideal.

A quick note per mission is plenty. Thanks!
